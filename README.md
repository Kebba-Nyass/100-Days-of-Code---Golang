## Day 1: Hello World

Getting started with Go: setting up the environment and writing the first program.
**What I learned:**
- Installing Go and verifying the setup with `go version`
- The structure of a Go program: `package main`, imports, and the `main()` function
- Printing output with the `fmt` package
- Running code with `go run` and compiling it with `go build`
**Run it:**
```bash
cd Day_1_Hello_World
go run main.go
```


## Day 2: Variables
# Learning how Go stores and handles data.
**What I learned:**
- Declaring variables with `var`
- Short declaration with `:=` (only inside functions)
- Basic types: `int`, `float64`, `string`, `bool`
- Zero values (the default value of a variable that is declared but not assigned)
- Constants with `const`
- Go's static typing and how unused variables cause compile errors
**Run it:**
```bash
cd Day_2_Variables
go run main.go
```
